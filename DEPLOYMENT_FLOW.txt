CHECKLISTS
───────────────────────────────────────────────────────────────────────────────

BEFORE DEPLOYMENT:
  ☐ npm test (all pass)
  ☐ git status (clean)
  ☐ git log (review commits)
  ☐ npm ci --omit=dev (build prod package)
  ☐ Ready? → git push origin master

DURING DEPLOYMENT:
  ☐ GitHub Actions running
  ☐ Watch: https://github.com/medwatchers/docflow/actions
  ☐ Typical time: 5-10 minutes

AFTER DEPLOYMENT:
  ☐ Health endpoint 200 OK
  ☐ Webhook test 200/400 OK
  ☐ Logs show no errors
  ☐ Monday board shows activity
  ☐ No Slack/PagerDuty alerts for 30 min
  ☐ Team confirms feature works

IF BROKEN:
  ☐ Run: .\rollback.ps1 -Mode Revert -Verify
  ☐ Wait 3-5 minutes
  ☐ Verify: https://doc-automation-func.azurewebsites.net/api/health
  ☐ Investigate root cause
  ☐ Fix locally, commit, try again
