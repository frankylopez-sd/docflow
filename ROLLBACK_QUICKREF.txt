================================================================================
  DOCFLOW ROLLBACK QUICK REFERENCE (Post-Deployment Failure)
================================================================================

SITUATION: Production deployment broken, need immediate recovery

================================================================================
OPTION 1: GIT REVERT (2-5 minutes to live)
================================================================================

Open PowerShell in C:\Users\Franky.Lopez\docflow:

  # Fastest one-liner rollback
  git revert HEAD --no-edit && git push origin master

Then:
  - GitHub Actions will run tests + deploy (~3-5 min)
  - Check status: https://github.com/medwatchers/docflow/actions
  - Verify health: https://doc-automation-func.azurewebsites.net/api/health

Advantage: Simple, auditable (git history shows revert)
Downtime: 30-120 seconds during deploy

Full command with verification:
  .\rollback.ps1 -Mode Revert -Verify

================================================================================
OPTION 2: BLUE-GREEN SLOT SWAP (10-30 seconds, if slots exist)
================================================================================

If staging slot exists:

  .\rollback.ps1 -Mode SlotSwap -Verify

Advantage: Instant, zero downtime, safe
Downtime: ~0 seconds (warm swap)

Check slot status first:
  az functionapp deployment slot list -g doc-automation-rg -n doc-automation-func

================================================================================
OPTION 3: EMERGENCY APP RESTART (30 seconds, last resort)
================================================================================

If app is hung/frozen:

  .\rollback.ps1 -Mode KillApp -Verify

WARNING: Only use if app is unresponsive and swap unavailable
Effect: Forces graceful app restart (kills w3wp process)
